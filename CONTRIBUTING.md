# Contributing

Obrigado por contribuir com esta implementação do desafio Kinvo.

Guidelines rápidas:

- Faça forks do repositório e trabalhe em branches nomeadas como `feat/xxx`, `fix/xxx`.
- Commits simples e atômicos. Use mensagens de commit no estilo Conventional Commits:
  - feat: descrição curta — para novas funcionalidades
  - fix: descrição curta — correção de bugs
  - chore: descrição curta — tarefas não relacionadas a código de produção
  - test: adicionar/ajustar testes
- Abra Pull Requests apontando `yourfork/feat/xxx` → `kinvoapp/kinvo-front-end-test:master` (ou `main`).
- Nos PRs, descreva o que foi implementado e qualquer limitação conhecida.

Testes locais

```bash
npm install
npm test
```

Contato

Se encontrar problemas com o desafio, abra uma issue no repositório original ou contate o recrutador.
